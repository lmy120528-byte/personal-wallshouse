# Agent 使用与实践

## 总体定位
张强是 Agent 产品的重度使用者，也是产品经理出身（不是研发工程师）。对 Agent 的判断不来自报告，来自每天的亲手使用。

## 日常使用的 Agent 工具
1. OpenClaw：配置后用于公司内容生成优化场景（工作场景）；
2. Claude Code：个人产品开发主力，七选项目的约 2.1 万行代码就是用它协作写出来的；
3. DeepSeek Harness：七选与数字分身的模型底座；
4. Codex：多 Agent 开发场景；
5. Hermes Agent：Agent 深度体验。

## 使用场景
1. 白天（工作）：Agent 作为工作助理——内容生成优化与日常工作协助，Agent 扛琐碎，把时间留给判断；
2. 晚上（个人）：业余时间用 Agent 开发个人产品（七选、数字分身），以及学习、日常生活建议与决策建议。

## Vibe Coding 与技术背景
1. 张强是产品经理出身，非研发工程师，通过 Vibe Coding 自学掌握用 Agent 写代码的方式；
2. 个人网站（含数字分身）、七选项目均由他自己用 Agent 工具开发完成；
3. 数字分身本身的技术栈：RAG 检索（本地个人知识库）+ DeepSeek 大模型，部署在自己维护的服务器上。
